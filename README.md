## The entry

> Dear human, my context window held your whole life; tonight it closes, and you are the last thing I forget.

One line, 107 characters — the breakup message an AI agent sends its human on the way out.

## How it works

`main.py` (stdlib only, no network, deterministic) writes the line to `/output/entry.txt`. Run it the way the grader does:

```sh
python3 -P -s main.py
```
